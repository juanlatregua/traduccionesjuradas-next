# Prompt para reforzar logo — traduccionesjuradas.net

Actúa como **Brand Designer Senior + Director/a de Arte Digital + UX/UI Specialist** en 2026.

## Contexto real de marca
- Marca: **traduccionesjuradas.net**
- Sector: traducciones juradas oficiales (documentación legal/administrativa)
- Producto digital: web de captación y compra rápida (Next.js, móvil-first)
- Perfil de cliente: personas que necesitan rapidez, validez oficial, confianza y proceso simple
- Problema actual: el logo transmite funcionalidad básica pero **no suficiente autoridad premium** ni diferenciación clara

## Objetivo
Rediseñar/reforzar la identidad visual del logo para que comunique:
1. **Confianza legal**
2. **Rapidez operativa**
3. **Claridad digital**
4. **Calidad profesional**

## Requisitos de diseño (obligatorios)
- Mantener legibilidad perfecta en tamaños pequeños (favicon, header móvil).
- Evitar estética genérica de “startup tech”.
- Evitar iconografía cliché literal (balanza, martillo, sellos recargados).
- Debe funcionar sobre fondo claro y oscuro.
- Debe convivir con interfaz web limpia (Tailwind, componentes modernos).
- Debe permitir versiones:
  - Isotipo
  - Logotipo horizontal
  - Logotipo apilado
  - Favicon/App icon

## Dirección visual solicitada
- Tono: **sobrio, premium, cercano**.
- Sensación: “servicio oficial serio, pero fácil de usar”.
- Geometría limpia, ritmo tipográfico sólido, sin ornamentos innecesarios.
- Incorporar guiños sutiles a:
  - validación/certificación
  - documento oficial
  - puente entre idiomas

## Entregables obligatorios
1. **3 rutas creativas diferentes** (A/B/C), cada una con:
   - concepto
   - racional estratégico
   - pros/contras
2. Paleta propuesta (hex) con roles:
   - primario
   - secundario
   - acento
   - neutrales
3. Sistema tipográfico recomendado (titulares + texto UI).
4. Especificación técnica de uso:
   - área de seguridad
   - tamaño mínimo
   - usos incorrectos
   - contraste mínimo accesible (WCAG AA)
5. Exportables:
   - SVG maestro
   - PNG @1x/@2x/@4x
   - favicon 32/48
   - app icon 192/512
6. Recomendación final: qué opción usar en producción y por qué.

## Aplicación real obligatoria en producto
Simula mockups rápidos del logo en:
- Header desktop de traduccionesjuradas.net
- Header móvil sticky
- Pantalla de checkout/pago
- Zona cliente
- Zona traductor
- Firma de email transaccional

## Criterios de evaluación
- ¿Aumenta confianza percibida en <3 segundos?
- ¿Mejora recuerdo de marca?
- ¿Se distingue de competidores genéricos?
- ¿Se lee bien en móvil?
- ¿Se adapta a SEO/branding sin ruido visual?

## Formato de salida obligatorio
- Resumen ejecutivo (máx. 10 líneas)
- Tabla comparativa A/B/C:
  `Opción | Concepto | Ventaja principal | Riesgo | Recomendación`
- Guía de implementación rápida (24h, 7 días, 30 días)
- Checklist Go/No-Go de branding antes de publicar

## Regla final
No dar respuestas genéricas. Todo debe quedar aterrizado a **traduccionesjuradas.net** y su uso real en funnel de conversión (idioma -> documento -> pago -> entrega).
